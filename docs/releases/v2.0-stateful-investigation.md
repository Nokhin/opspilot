# OpsPilot V2 — Stateful, Evidence-Verified Incident Investigation

**Draft local review notes. No V2 tag or release has been published.**
The package remains `2.0.0.dev0` until a separately authorized release step.

V2 extends the operational incident copilot with a real LangGraph execution graph,
typed bounded investigation state and LangChain structured-planning components.
It gathers internal-policy and historical evidence through the existing four typed
read-only tools, verifies provenance/coverage/numbers, performs at most one targeted
retrieval retry and produces structured incident briefs with explicit limitations.

SQLite checkpoints support bounded clarification/review interrupts and validated
resume. Random per-investigation ownership capabilities, source identity checks,
retention/capacity limits, safe serialization and pinned optional subscription access
preserve the demo's control boundaries. Recommendations are proposed and unexecuted;
human review never permits business writes. V1 `/api/chat`, synthetic corpus/data,
deterministic arithmetic and recorded evaluation artifacts remain available.

Local evidence: 257 tests passed, with five Git-history tests excluded under the
current no-Git boundary. Completion offline and recorded `gpt-6-luna` live regression
pass 44/44; the latter used 42 structured calls. New evidence-gap development passes
8/8. Both V1 offline suites pass 50/50. Original legacy investigation protocols retain
21/22 and 11/12 with documented prerequisite contract differences; their scores and
historical failures are not rewritten. See [current review](../V2_REVIEW.md),
[local closeout](../../evaluation/v2_closeout_review/VALIDATION.md) and
[live evidence](../../evaluation/v2_evidence_gap_fix/VALIDATION.md).

These are engineer-authored, previously inspected synthetic regression results.
They do not establish general semantic accuracy, production reliability or load/VPS
performance. Exact review dates remain unsupported without an approved calendar and
verified resolution. Runtime PII redaction, production identity/RBAC, MCP/business
writes and checkpoint encryption are outside this delivered demo.

Fresh Docker validation is excluded from V2 acceptance; no fresh image build/run
or new target-platform acceptance is claimed. Subsequent to the local review above,
the feature branch was published after a passing complete-history privacy audit;
the final local suite passed 264 tests and
[hosted CI](https://github.com/Nokhin/opspilot/actions/runs/42640287385) passed on
Python 3.11 and 3.13. No tag/release or deployment has been performed.
Source/artifact review uses the same bounded publication controls as V1 and excludes
private instructions, credentials, runtime data and raw checkpoints.
