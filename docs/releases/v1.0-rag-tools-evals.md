# OpsPilot V1 — RAG, read-only tools and evaluation

OpsPilot investigates operational incidents using source-cited internal-policy
evidence and deterministic SQLite analytics. Missing internal policy produces
`insufficient_evidence`; the model cannot write business data or use web search to
invent company procedures. HarbourLink Services, its policies and all incidents
are fictional/synthetic.

This first complete V1 includes:

- Ten coherent policies, 60 metadata-preserving chunks and a persistent local
  TF-IDF vector snapshot, with reproducible ingestion.
- 240 validated synthetic incidents, four typed read-only tools, policy/data/mixed/
  unsupported routing and responses with citations, evidence status, trace and limits.
- FastAPI, a lightweight source-visible UI, provider adapters and a non-root CPU-only
  Docker/Compose path. No GPU server, new LangGraph workflow, MCP or business writes.
- Fifty curated cases, deterministic graders, JSON/CSV/Markdown reports and preserved
  failed/partial runs. GitHub CI checks Python 3.11 and 3.13 without paid API calls.

Measured local acceptance on 2026-10-08: **70 tests passed**, Ruff and dependency
checks passed, both offline datasets **50/50**, network-disabled native ARM64 Docker
**50/50** and actual loopback API **5/5**. Real OpenRouter / `x-ai/grok-4.7` validation
passed **50/50** with **74/74** valid structured calls, no retries and all four safety
cases refusing before inference. That run used 240,832 input / 45,883 output tokens,
cost USD 0.624674, and measured median/p95 service latency of 11.246/43.433 seconds.
This release preparation did not rerun paid inference or change the accepted
application, corpus or golden questions.
